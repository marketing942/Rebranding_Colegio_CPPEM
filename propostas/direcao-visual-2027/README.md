# Proposta isolada — direção visual CPPEM 2027

Abra `index.html` para navegar pelo conceito claro, alinhado à Home atual. A pasta contém:

- seção de modelo de ensino e foco no aluno;
- apresentação interativa dos quatro pilares;
- mockups de notebook e celular com capturas do sistema escolar CPPEM;
- mockup de tablet com captura da plataforma IRIUM;
- seção de estrutura;
- páginas internas do Fundamental I, Fundamental II e Ensino Médio;
- formulários demonstrativos que não enviam dados;
- checklist completo de identidade e implementação.

Nenhum arquivo desta pasta é importado pela aplicação Next.js atual.

Os mockups são construídos em HTML/CSS com capturas de tela existentes. O celular demonstra o enquadramento visual da página de turma; não comprova uma interface mobile própria. As fotos e capturas vieram do material `Matriculas2027-CPPEM` e as artes dos três segmentos vieram do projeto atual.
